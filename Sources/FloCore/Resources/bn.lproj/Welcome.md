# Flo State-এ স্বাগতম

এই নোটবুকটি আসলে আপনার Documents ফোল্ডারে থাকা সাধারণ markdown ফাইলের একটি ফোল্ডার। যেকোনো অ্যাপ এগুলো খুলতে পারে, কিছুই আটকে থাকে না।

## লেখা

টাইপ করার সঙ্গে সঙ্গেই Markdown রূপ নেয়। আপনি যে লাইনে লিখছেন শুধু সেখানেই সিনট্যাক্স দেখা যায়, বাকি সব জায়গায় সরে থাকে: **বোল্ড**, _ইটালিক_, `কোড`, [লিঙ্ক](https://flocrivello.com/flostate/)।

- Return চাপলে তালিকা চলতে থাকে
- [ ] চেকবক্সও
- [x] টিক দিতে একটিতে ক্লিক করুন

## চলাফেরা

- **⌘K** যেকোনো কমান্ড চালায়। **⌘O** নাম দিয়ে কোনো নোটে নিয়ে যায়।
- **⌘⇧F** আপনার সব নোটের ভেতরে অনুসন্ধান করে।
- **⌘N** নতুন নোট তৈরি করে। **⌘T** নতুন ট্যাব খোলে।
- **⌘\\** সাইডবার দেখায় বা লুকায়।
- অন্য নোটে লিঙ্ক দিতে `[[` লিখুন, যেমন [[স্বাগতম]]।

## দৈনিক নোট

**⌘⇧D** আপনার দৈনিক নোটে আজকের এন্ট্রিতে নিয়ে যায়, আর তারিখের শিরোনাম না থাকলে সেটি যোগ করে।

## শিরোনাম গোটানো

কোনো শিরোনামের ওপর পয়েন্টার রেখে বাঁ পাশের তীরে ক্লিক করুন, তার নিচের সবকিছু গুটিয়ে যাবে। **⌘⌥←** সব শিরোনাম গুটিয়ে নেয় আর **⌘⌥→** সেগুলো খুলে দেয়।

## ছবি, টেবিল, গণিত ও ডায়াগ্রাম

একটি ছবি পেস্ট করুন বা টেনে আনুন: সেটি নোটের পাশের `attachments` ফোল্ডারে সংরক্ষিত হয়। আকার বদলাতে ছবির ওপর পয়েন্টার রেখে কোণের হ্যান্ডেল টানুন, অথবা নির্দিষ্ট আকারের জন্য রাইট-ক্লিক করুন।

| বৈশিষ্ট্য | শর্টকাট |
| --- | --- |
| কমান্ড প্যালেট | ⌘K |
| সব নোটে অনুসন্ধান | ⌘⇧F |

গণিত লেখা হয় LaTeX দিয়ে: $e^{i\pi} + 1 = 0$

```mermaid
graph LR
  ভাবনা --> খসড়া --> সম্পন্ন
```

## নিজের মতো করে নিন

**⌘,** সেটিংস খোলে: থিম, ফন্ট, আকার ও ব্যবধান। **⌘+** আর **⌘−** টেক্সটের আকার বদলায়।

যখন খুশি এই নোটটি মুছে ফেলুন। শুভ লেখালেখি।
