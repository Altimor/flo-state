# 欢迎使用 Flo State

这个笔记本只是“文稿”文件夹中的一个普通文件夹，里面是纯文本 Markdown 文件。任何 App 都能打开它们，不会被锁定在某个软件里。

## 书写

Markdown 会在你输入时即时渲染。语法只在你正在编辑的那一行显示，其他地方都会自动隐藏：**粗体**、_斜体_、`代码`、[链接](https://flocrivello.com/flostate/)。

- 按下 Return 键时列表会自动延续
- [ ] 复选框也一样
- [x] 点按即可勾选

## 快速浏览

- **⌘K** 运行任意命令。**⌘O** 按名称跳转到笔记。
- **⌘⇧F** 在所有笔记中搜索。
- **⌘N** 新建笔记。**⌘T** 打开新标签页。
- **⌘\\** 显示或隐藏边栏。
- 输入 `[[` 可链接到其他笔记，例如 [[欢迎]]。

## 每日笔记

**⌘⇧D** 跳转到每日笔记中今天的条目，如果还没有今天的日期标题，会自动添加。

## 折叠标题

将指针悬停在标题上，点按左侧的箭头即可折叠其下的所有内容。**⌘⌥←** 折叠所有标题，**⌘⌥→** 将其全部展开。

## 图像、表格、公式和图表

粘贴或拖入图像：它会存储在笔记旁的 `attachments` 文件夹中。将指针悬停在图像上并拖移角落的控制柄即可调整大小，或按住 Control 键点按以选择预设尺寸。

| 功能 | 快捷键 |
| --- | --- |
| 命令面板 | ⌘K |
| 搜索所有笔记 | ⌘⇧F |

公式使用 LaTeX：$e^{i\pi} + 1 = 0$

```mermaid
graph LR
  想法 --> 草稿 --> 完成
```

## 打造你的专属空间

**⌘,** 打开设置：主题、字体、字号和间距。**⌘+** 和 **⌘−** 可调整文字大小。

你可以随时删除这条笔记。祝书写愉快。
