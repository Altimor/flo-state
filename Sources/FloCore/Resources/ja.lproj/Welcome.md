# Flo Stateへようこそ

このノートブックは、「書類」フォルダ内にあるプレーンなMarkdownファイルのフォルダにすぎません。どのアプリでも開けるので、特定のアプリに縛られることはありません。

## 書く

Markdownは入力と同時に表示に反映されます。記法は編集中の行にだけ表示され、それ以外の場所では目立ちません: **太字**、_斜体_、`コード`、[リンク](https://flocrivello.com/flostate/)。

- リストはReturnキーを押すと続きます
- [ ] チェックボックスも同様です
- [x] クリックするとチェックが入ります

## 移動する

- **⌘K**であらゆるコマンドを実行できます。**⌘O**で名前を指定してノートに移動します。
- **⌘⇧F**ですべてのノート内を検索します。
- **⌘N**でノートを作成します。**⌘T**で新規タブを開きます。
- **⌘\\**でサイドバーを表示/非表示にします。
- `[[`と入力すると、[[ようこそ]]のように別のノートにリンクできます。

## デイリーノート

**⌘⇧D**でデイリーノートの今日の項目に移動します。日付の見出しがまだなければ追加されます。

## 見出しの折りたたみ

見出しにポインタを重ね、左側の矢印をクリックすると、その下の内容がすべて折りたたまれます。**⌘⌥←**ですべての見出しを折りたたみ、**⌘⌥→**で展開します。

## イメージ、表、数式、ダイアグラム

イメージをペーストまたはドロップすると、ノートと同じ場所にある`attachments`フォルダに保存されます。イメージにポインタを重ねて角のハンドルをドラッグするとサイズを変更でき、右クリックするとプリセットのサイズを選べます。

| 機能 | ショートカット |
| --- | --- |
| コマンドパレット | ⌘K |
| すべてのノートを検索 | ⌘⇧F |

数式にはLaTeXを使います: $e^{i\pi} + 1 = 0$

```mermaid
graph LR
  アイデア --> 下書き --> 完了
```

## 自分好みに

**⌘,**で設定を開けます: テーマ、フォント、サイズ、間隔。**⌘+**と**⌘−**でテキストサイズを変更できます。

このノートはいつでも削除してかまいません。楽しく書きましょう。
