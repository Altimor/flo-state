# Flo State میں خوش آمدید

یہ نوٹ بک آپ کے Documents فولڈر میں سادہ markdown فائلوں کا ایک فولڈر ہی ہے۔ کوئی بھی ایپ انہیں کھول سکتی ہے، اور کچھ بھی بند نہیں ہے۔

## لکھنا

Markdown لکھتے ہی رینڈر ہوتا ہے۔ جس لائن پر آپ ترمیم کر رہے ہیں وہاں سنٹیکس نظر آتا ہے اور باقی ہر جگہ ہٹ جاتا ہے: **بولڈ**، _اٹالک_، `code`، [لنکس](https://flocrivello.com/flostate/)۔

- Return دبانے پر فہرستیں جاری رہتی ہیں
- [ ] چیک باکس بھی
- [x] نشان لگانے کے لیے کسی پر کلک کریں

## ادھر ادھر جانا

- **⌘K** کوئی بھی کمانڈ چلاتا ہے۔ **⌘O** نام سے کسی نوٹ پر لے جاتا ہے۔
- **⌘⇧F** آپ کے تمام نوٹس کے اندر تلاش کرتا ہے۔
- **⌘N** نیا نوٹ بناتا ہے۔ **⌘T** نیا ٹیب کھولتا ہے۔
- **⌘\\** سائڈبار دکھاتا یا چھپاتا ہے۔
- کسی اور نوٹ سے لنک کرنے کے لیے `[[` لکھیں، جیسے [[خوش آمدید]]۔

## روزانہ نوٹس

**⌘⇧D** آپ کے روزانہ نوٹ میں آج کے اندراج پر لے جاتا ہے، اور اگر تاریخ والی سرخی موجود نہ ہو تو اسے شامل کر دیتا ہے۔

## سرخیاں سمیٹیں

کسی سرخی پر ہوور کریں اور اس کے نیچے سب کچھ سمیٹنے کے لیے اس کے بائیں جانب تیر پر کلک کریں۔ **⌘⌥←** تمام سرخیاں سمیٹتا ہے اور **⌘⌥→** انہیں پھیلاتا ہے۔

## تصاویر، ٹیبلز، ریاضی اور خاکے

کوئی تصویر پیسٹ کریں یا ڈراپ کریں: یہ نوٹ کے ساتھ والے `attachments` فولڈر میں محفوظ ہو جاتی ہے۔ سائز بدلنے کے لیے اس پر ہوور کر کے کونے کا ہینڈل گھسیٹیں، یا پہلے سے طے شدہ سائز کے لیے رائٹ کلک کریں۔

| خصوصیت | شارٹ کٹ |
| --- | --- |
| کمانڈ پیلیٹ | ⌘K |
| تمام نوٹس میں تلاش | ⌘⇧F |

ریاضی کے لیے LaTeX استعمال ہوتا ہے: $e^{i\pi} + 1 = 0$

```mermaid
graph LR
  خیال --> مسودہ --> مکمل
```

## اسے اپنا بنائیں

**⌘,** سیٹنگز کھولتا ہے: تھیمز، فونٹس، سائز اور فاصلہ۔ **⌘+** اور **⌘−** متن کا سائز بدلتے ہیں۔

جب چاہیں یہ نوٹ حذف کر دیں۔ لکھنے کا لطف اٹھائیں۔
