# مرحبًا بك في Flo State

هذا الدفتر مجرد مجلد من ملفات Markdown عادية داخل مجلد المستندات. يمكن لأي تطبيق فتحها، ولا شيء مقيّد بتطبيق واحد.

## الكتابة

يُعرض تنسيق Markdown أثناء الكتابة. تظهر الصيغة في السطر الذي تحرره فقط وتختفي في كل مكان آخر: **غامق**، _مائل_، `كود`، [روابط](https://flocrivello.com/flostate/).

- تستمر القوائم عند الضغط على Return
- [ ] وكذلك مربعات الاختيار
- [x] انقر على أحدها لتحديده

## التنقل

- **⌘K** يشغّل أي أمر. **⌘O** ينتقل إلى ملاحظة باسمها.
- **⌘⇧F** يبحث داخل كل ملاحظاتك.
- **⌘N** ينشئ ملاحظة. **⌘T** يفتح علامة تبويب جديدة.
- **⌘\\** يُظهر الشريط الجانبي أو يخفيه.
- اكتب `[[` للربط بملاحظة أخرى، مثل [[مرحبًا]].

## الملاحظات اليومية

**⌘⇧D** ينتقل إلى مدخل اليوم في ملاحظتك اليومية، ويضيف عنوانًا بالتاريخ إن لم يكن موجودًا.

## طي العناوين

مرّر المؤشر فوق عنوان وانقر على السهم بجانبه لطي كل ما تحته. **⌘⌥←** يطوي كل العناوين و**⌘⌥→** يوسّعها.

## الصور والجداول والرياضيات والمخططات

الصق صورة أو أفلتها: تُحفظ في مجلد `attachments` بجانب الملاحظة. مرّر المؤشر فوقها واسحب مقبض الزاوية لتغيير حجمها، أو انقر بزر الماوس الأيمن لاختيار أحجام جاهزة.

| الميزة | الاختصار |
| --- | --- |
| لوحة الأوامر | ⌘K |
| البحث في كل الملاحظات | ⌘⇧F |

تستخدم الرياضيات LaTeX: $e^{i\pi} + 1 = 0$

```mermaid
graph LR
  فكرة --> مسودة --> تم
```

## اجعله على ذوقك

**⌘,** يفتح الإعدادات: السمات والخطوط والأحجام والتباعد. **⌘+** و**⌘−** يغيّران حجم النص.

احذف هذه الملاحظة متى شئت. كتابة ممتعة.
